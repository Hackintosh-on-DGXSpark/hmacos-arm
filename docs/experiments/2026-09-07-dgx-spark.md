## Commands

All commands below run on the Spark. Connection options used throughout:
`ssh -o BatchMode=yes -o ConnectTimeout=15 dsec-dgx-spark`.
Sources are the files under this project's `experiments/`, copied to remote `src/`.

Only user-space tool packages were downloaded and extracted. Nothing was
installed into the system package database, and no repositories were added:

```sh
env -C /home/spark/hmacos-arm/packages apt-get download \
  vulkan-tools=1.4.328.1+dfsg1-1~1 libvulkan-dev=1.4.328.1-1~1 \
  glslang-tools=16.0.0-1~1 spirv-tools=2025.4-1~ppa2
for package in /home/spark/hmacos-arm/packages/*.deb; do
  dpkg-deb -x "$package" /home/spark/hmacos-arm/sysroot
done
```

Packages came from the host's existing Canonical/NVIDIA Vulkan repository.
The four packages total about 7.1 MB. Download/extraction exited `0`.

Reproduce the successful tests:

```sh
ROOT=/home/spark/hmacos-arm
cc -O2 -Wall -Wextra -Werror "$ROOT/src/kvm_probe.c" -o "$ROOT/bin/kvm-probe"
sudo -n -u spark -g kvm timeout 10s "$ROOT/bin/kvm-probe"

cc -O2 -Wall -Wextra -Werror -DPROBE_16K -DPROBE_VMAPPLE_HVC \
  "$ROOT/src/kvm_probe.c" -o "$ROOT/bin/kvm-vmapple-probe"
sudo -n -u spark -g kvm timeout 10s "$ROOT/bin/kvm-vmapple-probe"

"$ROOT/sysroot/usr/bin/glslangValidator" -V --target-env vulkan1.2 \
  "$ROOT/src/vulkan_compute.comp" -o "$ROOT/bin/vulkan-compute.spv"
"$ROOT/sysroot/usr/bin/spirv-val" --target-env vulkan1.2 "$ROOT/bin/vulkan-compute.spv"
cc -O2 -Wall -Wextra -Werror -I"$ROOT/sysroot/usr/include" \
  "$ROOT/src/vulkan_compute.c" -Wl,-l:libvulkan.so.1 -o "$ROOT/bin/vulkan-compute"
VK_DRIVER_FILES=/usr/share/vulkan/icd.d/nvidia_icd.json \
  timeout 15s "$ROOT/bin/vulkan-compute" "$ROOT/bin/vulkan-compute.spv"

cc -O2 -Wall -Wextra -Werror -DPROBE_HOST_IMPORT -I"$ROOT/sysroot/usr/include" \
  "$ROOT/src/vulkan_compute.c" -Wl,-l:libvulkan.so.1 -o "$ROOT/bin/vulkan-host-import"
VK_DRIVER_FILES=/usr/share/vulkan/icd.d/nvidia_icd.json \
  timeout 15s "$ROOT/bin/vulkan-host-import" "$ROOT/bin/vulkan-compute.spv"
```

Negative controls, both intentionally exit `1`:

```sh
cc -O2 -Wall -Wextra -Werror -DTEST_EXPECTED_VALUE=0 \
  "$ROOT/src/kvm_probe.c" -o "$ROOT/bin/kvm-probe-negative"
sudo -n -u spark -g kvm timeout 10s "$ROOT/bin/kvm-probe-negative"
VK_DRIVER_FILES=/usr/share/vulkan/icd.d/lvp_icd.json \
  timeout 15s "$ROOT/bin/vulkan-compute" "$ROOT/bin/vulkan-compute.spv"
```

Compilation and shader validation exited `0` with no compiler warnings.
Commands were captured with `script -q -e -c 'COMMAND' LOGFILE` so failed test
exit statuses are retained. The Vulkan summary's missing DISPLAY message is
expected over headless SSH; it does not invalidate the physical-device results.

## macOS Status

**No macOS guest boot or guest Metal execution has been established.**

- The remote `artifacts/` directory is empty. A provisioned macOS disk, its
  matching AUX/NVRAM state, and VM identity are not supplied in the project.
  The local Mac has Apple's `AVPBooter.vmapple2.bin`, but it was not copied.
- The [Asahi integration](https://github.com/steelbrain/experiment-macOS-arm64-on-asahi-linux-arm64)
  handles Apple-specific APCTL/KERNKEY state. This Spark experiment confirms
  APCTL is not exposed here, so that implementation is not a drop-in generic
  Arm KVM solution. HVC forwarding works; Apple's service semantics remain work.
- The [AnyOS project](https://github.com/medfa12/apple-silicon-anyos-project)
  remains at `59fd73aac4ae386939bc69dc58dffbce1b2167b2`. Its published QEMU root
  tree lacks `target/`, including ARM architecture sources. A fresh GitHub tree
  query confirmed the omission; its full build was not attempted.
- [Reims](https://github.com/steelbrain/reims-vgpu) was checked at
  `69a57dd69a6958e946c03b73e02db331f330f435`. It remains the graphics integration
  candidate, not a tested component of these probes.

These tests establish host prerequisites and useful interfaces. They do not
test complete Apple PAC semantics, SMP, timer interrupts, WindowServer, image
rendering, or full macOS installation. The 16 KiB test uses L2 block descriptors.
No kernel/firmware/driver replacements, GPU unbinding, or host-security changes
were performed. Probe processes terminate after each bounded run.
